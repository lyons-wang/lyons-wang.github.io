Neural Representation of Dance

Final Project for NEUR1660: Neural Computation in Learning and Decision Making

Abstract:

This project explores how reinforcement learning can model aspects of human dance learning. Using Q-learning, we trained an agent to learn a fixed choreography sequence through trial and error, integrating rhythm, movement memory, and feedback. We compared multiple reward structures and state representations to investigate how sequencing, timing, and intermediate feedback influence the learning of complex dance patterns.

Key Results:

  • Chunked/curriculum learning dramatically outperformed sparse reward learning for choreography acquisition
  • Intermediate feedback was critical for learning long movement sequences effectively
  • Models with explicit sequence-position memory consistently outperformed rhythm-only state representations

To summarize: these results suggest that both reward structure and state representation strongly influence an agents' ability to learn sequential choreography. While reinforcement learning was effective for reproducing fixed movement patterns, the project also highlighted important limitations in modeling the creativity, flexibility, and embodiment involved in real human dance learning.

Figure 1: Comparison of reward structures during choreography learning. The chunked/curriculum model steadily improved and eventually mastered the full 32-move sequence, while sparse reward and random baseline models showed little learning.

Figure 2: Comparison of the two strongest learning approaches. Both memorization and chunked/curriculum learning achieved full-sequence mastery, though curriculum learning progressed more gradually through smaller movement sections.

Go AI Agent

MCTS, IDS, and Heuristic Design

Go AI Agent

Final Project for CSCI0410: Foundations of AI & Machine Learning

Abstract:

This project explored artificial intelligence strategies for playing 5x5 Go under strict time constraints. I implemented and compared multiple search-based agents, including Minimax, Alpha-Beta Pruning, Iterative Deepening Search (IDS), and Monte Carlo Tree Search (MCTS), before developing a hybrid agent that combined adversarial search with probabilistic exploration. The project investigated how different search strategies balance computational efficiency, board evaluation quality, and decision-making under limited time budgets.

Hybrid Agent Design

The final agent used a hybrid strategy that adapted to different stages of the game. During the opening, the agent prioritized center control to establish strong early influence while avoiding unnecessary search during the highest-branching portion of the game. This opening strategy was inspired by 5x5 Go analysis from Sensei's Library.

In the early and middle game, the agent relied on Monte Carlo Tree Search (MCTS), which explored possible outcomes through probabilistic simulations rather than depending entirely on heuristic evaluation. In the late game, when fewer legal actions remained (< 10), the agent switched to Iterative Deepening Search (IDS), allowing deeper tactical evaluation of more developed board states.

This hybrid design combined the strengths of both approaches: broad exploration during complex early-game positions and more precise more precise heuristic-guided evaluation during the late game.

Heuristic Design

The heuristic evaluation function estimated board strength using both stone count and controlled territory. Existing stones on the board were weighted heavily because they represented secured points and stable board presence.

To evaluate territory, the agent searched for connected empty regions using a flood-fill algorithm. The algorithm iterated across the board and expanded through neighboring empty intersections to identify contiguous empty regions. During the search, the agent tracked which player's stones bordered each region. If a region was completely surrounded by only one player, the region was counted as controlled territory and added to that player's score. This territory evaluation strategy was inspired by traditional Go scoring principles described by the Pandanet Go Guide .

The final heuristic combined weighted stone count and territorial control into a single evaluation score representing overall board strength. Positive scores favored black, while negative scores favored white. Territorial regions were weighted less heavily than placed stones because territory can still be invaded or reduced later in the game.

Results:

The hybrid agent performed competitively under tournament evaluation by combining probabilistic exploration during the early game with deeper heuristic-guided evaluation in the late game. Iterative Deepening Search consistently outperformed standard Monte Carlo Tree Search in many local tests, largely because heuristic evaluation was more computationally efficient than repeated Monte Carlo rollouts under strict time constraints.

Interestingly, the Greedy agent also performed competitively against several stronger search-based agents. On a small 5x5 board, immediate positional advantages and local captures can already provide strong short-term evaluations, allowing simpler heuristic-based decision making to remain surprisingly effective despite limited lookahead.

Although the hybrid model sometimes underperformed locally due to rollout speed limitations, it achieved the strongest overall performance on the Gradescope autograder evaluation. This suggests that the hybrid approach was able to balance exploration and tactical evaluation effectively under the official testing environment and time controls.

One major limitation of the project was runtime performance. Because the implementation used a PyGame/PyGo-based environment, Monte Carlo rollouts were relatively slow, causing MCTS to occasionally exceed time limits and forfeit games. As a result, some tournament outcomes likely reflected both strategic strength and computational efficiency rather than pure gameplay quality.

Figure 1: Tournament win-rate heatmap comparing implemented agents across local matchups. In this small local sample, the Greedy agent performed surprisingly well, likely because immediate positional advantages are especially valuable on a 5x5 board. MCTS performed poorly across matchups, likely due to slow rollout computation and time-limit issues.

Experiments with different MCTS exploration constants also demonstrated how exploration-exploitation tradeoffs influenced search behavior and move selection. Lower exploration constants caused the search to focus heavily on a smaller number of promising actions, while higher values distributed simulations more broadly across the board.

Figure 2: Distribution of MCTS visits across actions for different exploration constants. Lower values of c encouraged exploitation, while larger values increased exploration across available actions.

Future Work:

One possible extension would terminate flood-fill searches early when mixed-color borders are detected, avoiding unnecessary exploration of regions that cannot contribute to territory scoring.

Privacy in the Healthcare System

Ethical Challenges in Healthcare Data

Privacy in the Healthcare System

Final Project for CSCI1805: Computers, Freedom, and Privacy

Abstract:

This project examined how modern digital health technologies have outpaced traditional healthcare privacy regulations such as HIPAA. Through analysis of legal frameworks, cybersecurity risks, and ethical implications, the project explored how wearable devices, telehealth platforms, and third-party health applications create new challenges for patient privacy in the digital age.

Core Challenges

  • HIPAA does not regulate many modern digital health platforms
  • Healthcare data breaches have sharply increased in the digital era
  • Third-party apps and wearables collect sensitive patient data with limited oversight
  • Fragmented state and federal laws create regulatory complexity

Ethical Concerns

  • Risk of re-identification from “anonymous” datasets
  • Commercial exploitation of patient data
  • Threats to patient autonomy and confidentiality
  • Disproportionate harm to vulnerable populations

Policy Recommendations

  • Expand FTC oversight of digital health technologies
  • Establish national privacy and cybersecurity standards
  • Limit third-party data sharing and commercialization
  • Create certification and accountability frameworks

Neural Signal Processing & Connectivity Analysis

Spectral Analysis, Granger Causality, GLMs, and Kalman Filtering

Neural Signal Processing & Connectivity Analysis

Final Exam for NEUR2110: Statistical Neuroscience

Abstract:

This project explored a range of computational neuroscience methods for analyzing neural signals, connectivity, and dynamical systems. Using stochastic process analysis, spectral estimation, Granger causality, generalized linear models (GLMs), and Kalman filtering, the project investigated how statistical and dynamical modeling techniques can be used to characterize neural activity across both continuous and spike-train data.

Analyses included spectral coherence estimation, effective connectivity inference, point-process modeling of neuronal spiking, and latent state estimation in Gaussian linear dynamical systems. Together, these methods demonstrate how modern computational approaches can uncover structure, information flow, and temporal dynamics in complex neural systems.

Spectral & Connectivity Analysis:

I explored how spectral and connectivity-based methods can be used to characterize interactions within multichannel neural systems. Multivariate autoregressive (VAR) modeling and multitaper spectral estimation were used to analyze oscillatory structure, spectral power, coherence, and directed information flow across neural channels.

VAR-based spectral estimates revealed prominent oscillatory peaks near 30 Hz across several channels, while other channels exhibited slower low-frequency dynamics and broader spectral structure. These results demonstrated how different neural populations can exhibit distinct frequency-domain behavior despite belonging to the same overall network.

Figure 1: VAR-based spectral power estimates across neural channels revealed distinct oscillatory and low-frequency activity patterns throughout the network.

Conditional Granger causality analysis further identified directed interactions between channels, producing a sparser and more selective connectivity structure than pairwise coherence alone. Strongest interactions were concentrated primarily within lower-frequency dynamics, suggesting that slower oscillatory activity contributed substantially to directed information flow across the network.

Figure 2: Conditional Granger causality analysis revealed directed information flow within the inferred neural network, highlighting selective causal interactions between subsets of channels.

Spike Train Modeling:

Point-process generalized linear models (GLMs) were used to characterize temporal interactions between neurons using spike train data. Auto-history and cross-history filters were constructed using raised-cosine basis functions, allowing neuronal firing probability to be modeled as a function of both intrinsic spiking history and activity from other neurons.

Bootstrap confidence intervals were then used to evaluate the statistical significance of inferred temporal coupling. The resulting cross-history filter demonstrated a significant excitatory effect from one neuron onto another at short positive time lags, consistent with directed statistical coupling within the modeled system.

Figure 3: Estimated cross-history temporal filter with bootstrap confidence intervals, demonstrating statistically significant directed coupling between neurons at short positive time lags.

State-Space Modeling & Kalman Filtering:

Gaussian linear dynamical systems and Kalman filtering were used to estimate latent neural states from noisy observations. Model parameters were first estimated from training data before recursive Bayesian filtering was applied to infer hidden system dynamics over time.

The inferred posterior trajectories closely tracked the true latent states, demonstrating how Kalman filtering can effectively recover underlying neural dynamics from noisy measurements.

Figure 4: True latent states and Kalman-filtered posterior estimates over time, demonstrating accurate reconstruction of hidden system dynamics from noisy observations.

Polls in 2020

Polling Error, Bias, and Election Data Analysis

Polls in 2020

Individual Data Project

Abstract:

Polling error is often treated as random noise, but this project asks whether 2020 polling misses followed structured patterns related to timing, partisanship, pollster quality, and election-wide dynamics.

Key Findings:

  • Polling error was widely dispersed and not tightly centered around zero, suggesting structured variation rather than simple random noise.
  • Polling error evolved systematically as Election Day approached, with late-campaign polls exhibiting greater asymmetry and volatility.
  • Partisan-sponsored polls showed significantly different error distributions even after accounting for campaign timing.
  • Higher-rated pollsters tended to underestimate outcomes on average, despite generally being considered more reliable.
  • Pollster quality predicted the direction of polling error more strongly than the magnitude of large polling misses.

Polling Error Over Time:

Polling error evolved systematically as Election Day approached rather than remaining stable throughout the campaign. Late-campaign polls exhibited greater asymmetry and larger deviations, suggesting that polling behavior changes over the course of an election cycle rather than simply reflecting constant random variation.

Figure 1: Polling error as a function of time until Election Day. Individual points represent polls, while the LOESS-smoothed trend highlights systematic changes in polling behavior across the campaign cycle.

Partisanship & Sponsorship:

Partisan and nonpartisan polls followed different timing patterns throughout the election cycle, complicating direct comparisons of polling error. Nonpartisan polls clustered closer to Election Day, while partisan-sponsored polls were distributed more evenly across the campaign.

Figure 2: Kernel density estimates of poll timing by partisan sponsorship, demonstrating that partisan and nonpartisan polls were conducted at systematically different points in the campaign cycle.

Even after accounting for timing differences, polling error distributions varied substantially between Democratic- and Republican-sponsored polls. Democratic-sponsored polls tended to exhibit more positive signed error, while Republican-sponsored polls tended to exhibit more negative signed error and were generally more accurate on average.

Figure 3: Distribution of signed polling error across Democratic- and Republican-sponsored polls, demonstrating systematic differences in both error direction and magnitude.

Pollster Quality Analysis:

Pollster quality was also associated with systematic differences in polling error. Surprisingly, higher-rated pollsters did not simply produce errors closer to zero. Instead, higher pollster ratings were associated with increasingly negative signed polling error on average.

Figure 4: Relationship between pollster quality and signed polling error. Higher-rated pollsters tended to underestimate outcomes on average, despite generally being viewed as more reliable.

After controlling for campaign timing, partisan sponsorship, and sample size using OLS regression, pollster quality still significantly predicted the direction of polling error. However, this raised a broader question: were polling misses primarily driven by individual pollster performance, or by election-wide dynamics affecting nearly all pollsters simultaneously?

To investigate this, I removed race-level average polling error and examined whether higher-rated pollsters still systematically differed from lower-rated pollsters within the same races. Even after accounting for shared race-level effects, higher-rated pollsters continued to exhibit more negative within-race polling error on average.

Figure 5: Relationship between pollster quality and within-race polling error after removing race-level average effects. The persistence of this pattern suggests that polling error in 2020 reflected both pollster-specific tendencies and broader election-wide dynamics.

Effects of Neuronal Population Size

ECoG Face & House Decoding

Scaling Effects of Neuronal Population Size on ECoG-Based House & Face Decoding

Final Project for NEUR0680: Introduction to Computational Neuroscience

Abstract:

This project explored how neuronal population size influences the decoding of visual stimuli using electrocorticography (ECoG) data. Using broadband neural activity recorded from human ventral temporal cortex, we analyzed category-selective responses to faces and houses across implanted electrodes. We then simulated reductions in neuronal population size by lesioning subsets of channels to examine how response strength and interpretability changed as spatial resolution decreased. The project replicated several findings from prior literature regarding face- and house-selective activity, while also revealing challenges in quantitatively linking electrode-level activity to decoding accuracy. Overall, the project combined signal processing, neural data analysis, and computational neuroscience methods to investigate how distributed cortical populations contribute to visual perception.

Key Results:

  • Successfully identified face-selective and house-selective electrode responses using broadband ECoG activity
  • Lesioning selective channels substantially reduced response magnitude and disrupted interpretable category-specific activity patterns
  • Heatmap visualizations revealed consistent trial-by-trial temporal dynamics across selective electrodes
  • The project highlighted the importance of careful electrode selection and preprocessing when interpreting population-level neural decoding

To summarize: the results suggest that distributed neuronal populations play a critical role in visual category representation, while also demonstrating the challenges of scaling electrode-level analyses into quantitative decoding models.

Figure 1: Averaged broadband neural responses across 50 ECoG channels during face and house presentation trials. Strong category-selective responses emerged primarily in channels 42-47, suggesting localized face- and house-selective activity within ventral temporal cortex.

Figure 2: Trial-by-trial heatmap visualization of broadband neural activity aligned to stimulus onset. Increased activity following stimulus presentation demonstrates consistent temporal response dynamics across selective electrodes.

Decision Tree Classifier

Recursive Classification

Decision Tree

Project for CSCI0200: Program Design with Data Structures & Algorithms

Abstract:

This project implemented a decision tree classifier in Java using recursive tree construction. The model takes in CSV datasets, selects attributes to split on, builds internal attribute nodes and decision leaves, and recursively traverses the resulting tree to classify new data. The project focused on understanding supervised learning from the ground up by implementing the core data structures and logic behind a simple interpretable classifier.

Tree Structure & Classification:

The classifier represents each decision point as an attribute node, where outgoing edges correspond to possible values of the selected attribute. Each edge leads either to another attribute node or to a decision leaf containing the final predicted outcome. Each decision point is represented as an attribute node, where outgoing edges correspond to possible values of that attribute. Each edge leads either to another attribute node or to a decision leaf containing the final predicted outcome.

During classification, a new row is passed through the tree recursively. At each attribute node, the classifier checks the row's value for the selected attribute and follows the matching edge. If no matching edge is found, the tree returns a default prediction based on the most common outcome in the training data.

Dataset Processing:

The dataset class handled the core preprocessing logic needed to build the tree. It identified possible values for each attribute, split rows into smaller subsets based on attribute values, removed attributes after they were used for splitting, and calculated default predictions from the most common target value.

This project emphasized object-oriented design, recursive algorithms, and the fundamentals of supervised learning by building the structure of a decision tree classifier from scratch.
