Neural Representation of Dance

Final Project for NEUR1660: Neural Computation in Learning and Decision Making

Abstract:

This project explores how reinforcement learning can model aspects of human dance learning. Using Q-learning, we trained an agent to learn a fixed choreography sequence through trial and error, integrating rhythm, movement memory, and feedback. We compared multiple reward structures and state representations to investigate how sequencing, timing, and intermediate feedback influence the learning of complex dance patterns.

Key Results:

  • Chunked/curriculum learning dramatically outperformed sparse reward learning for choreography acquisition
  • Intermediate feedback was critical for learning long movement sequences effectively
  • Models with explicit sequence-position memory consistently outperformed rhythm-only state representations

To summarize: these results suggest that both reward structure and state representation strongly influence an agents' ability to learn sequential choreography. While reinforcement learning was effective for reproducing fixed movement patterns, the project also highlighted important limitations in modeling the creativity, flexibility, and embodiment involved in real human dance learning.

Above: Comparison of reward structures during choreography learning. The chunked/curriculum model steadily improved and eventually mastered the full 32-move sequence, while sparse reward and random baseline models showed little learning.

Above: Comparison of the two strongest learning approaches. Both memorization and chunked/curriculum learning achieved full-sequence mastery, though curriculum learning progressed more gradually through smaller movement sections.
